Lector local de PDF

Procesa documentos en el equipo, recupera fragmentos relevantes y utiliza un modelo local de Ollama para contestar preguntas. Este modelo parte de un trabajo previamente elaborado y trabajado, su modificacion fue hecha para ser entregado a la Universidad Cuauhthemoc.

Operación local

Las conversaciones y los PDF se almacenan únicamente en la carpeta local data.

Método documental

El archivo se extrae, fragmenta e indexa. El modelo no se reentrena con cada PDF.

Integridad

Un manifiesto firmado valida los archivos protegidos al iniciar la aplicación.
